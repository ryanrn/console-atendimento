# Console de Atendimento

Sistema web desenvolvido para facilitar a rotina da equipe de suporte, centralizando informações e ferramentas utilizadas diariamente.

## Funcionalidades

- **Respostas prontas:** consulte, pesquise, copie e favorite orientações.
- **Contatos:** encontre rapidamente telefones e ramais dos setores.
- **Links úteis:** acesse sistemas e ferramentas da equipe.
- **Pesquisa global:** encontre respostas, contatos e links em uma única pesquisa.
- **Bloco de notas:** anotações privadas de cada usuário.
- **Gerenciamento de equipe:** controle de usuários e permissões.
- **Favoritos:** organize os itens mais utilizados, com preferência individual.

## Tecnologias

- HTML, CSS e JavaScript
- Supabase — banco de dados e autenticação
- Vercel — hospedagem

## Permissões

**Administrador:** gerencia usuários e informações compartilhadas.

**Membro:** consulta informações, copia conteúdos e organiza seus favoritos.

## Objetivo

Agilizar os atendimentos, padronizar orientações e facilitar o acesso às informações utilizadas pela equipe.

## Observações

- O acesso é individual.
- As informações compartilhadas ficam armazenadas no Supabase.
- Não devem ser armazenados dados sensíveis de pacientes, senhas ou credenciais.
- O sistema não substitui as plataformas oficiais de atendimento.
